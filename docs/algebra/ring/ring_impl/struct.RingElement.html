Struct RingElement

Source 
#[repr(transparent)]
pub struct RingElement<T: IntRing2k + Display>(pub T);
Expand description

The RingElement type is a wrapper for all datatypes implementing the IntRing2k trait to explicitly allow wrapping arithmetic opearations.

View a slice of RingElement<T> as raw bytes, zero-copy.

§Safety rationale
  • RingElement<T> is #[repr(transparent)] over T.
  • T: IntRing2k is a primitive integer stored in native byte order.
  • On little-endian platforms the in-memory layout matches the little-endian wire format used by IntRing2k::write.
  • We assert at compile time that the target is little-endian.
